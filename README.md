# Flirt App Client

This is a flirt bot chatting app. It features interactive chat interfaces, user profile management, customizable themes, and local storage for chat history[cite: 2]. 

## Features
- **Chat & Conversations:** Interactive chat interfaces with custom message bubbles and reply options[cite: 2].
- **Profiles:** Built-in profiles and image assets for characters like Jessica, Olivia, and Taylor[cite: 2].
- **Local Storage:** Saves your chat history, login state, and user preferences locally[cite: 2].
- **Customization:** Toggle application themes and sound settings via the settings screen[cite: 2].
